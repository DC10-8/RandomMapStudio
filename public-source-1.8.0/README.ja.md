# Random Map Studio 1.8.0

Cities: Skylines 1用のランダム地形生成MODです。新規ゲーム開始後、UUIから使います。

## 導入・操作

日本語・英語を一つのDLLに統合しています。統合版だけを導入し、旧版のファイルを置き換えてください。ZIP内のRandomMapStudioフォルダーを `%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods` へコピーし、MODとUnified UIを有効にします。旧版を置き換える際はゲームを終了してください。

1. 新規ゲームでマップを選び「スタート」を押します。
2. 都市画面でUUIの地形アイコンをクリックします。
3. 陸地・海・山地の割合を合計100％で指定します。山地は陸地と別枠です。必要なら川をチェックします。
4. 「生成」でパネル内の候補を表示します。何度でも繰り返せます。この段階ではゲーム内を変更しません。
5. 「作成」で表示中の候補を地形へ反映し、海・湖・川の水を初期配置します。
6. 通常のゲーム保存で都市を保存します。

MODのオプション「Language / 言語」で日本語・英語を変更できます。既存パネルは生成・作成処理の途中でも即時に言語を更新します。入力値・パネル位置・候補を維持します。保存した言語設定を優先します。保存設定がなければ、システムUIが日本語の場合は日本語、それ以外は英語で始まります。

## 機能と制限

- UIは新規ゲーム専用です。セーブのロード、マップエディター、シナリオ開始では表示しません。
- 正方形グリッドのサイズを自動検出します。16 m間隔、座標原点−8640 mの地形を対象とし、HundredTilesの正方向拡張座標・樹木の圧縮座標に対応する処理を含みます。地形領域の拡張自体は別MODで行ってください。
- 川は海・湖の岸またはマップ端へ接続し、水底を掘り進めません。海面と同じ40 mの水位を使い、流速・勾配を再現する水文学的モデルではありません。川を掘ると面積比率が変わります。候補ルートに陸上区間がなければ川は作られません。
- 作成時に道路・線路・護岸・堤防・運河・壁・ダム・建物を撤去します。道路・鉄道等の外部接続も削除し、自動で再作成しません。
- 水域の樹木を削除し、陸地に残す樹木は新しい地面の高さへ合わせます。独立したプロップと天然資源は残します。
- 「元の地形に戻す」は最初の作成前の地形・水面・砂地の塗装等を復元します。撤去した構造物・樹木や、全てのシミュレーション過渡状態は復元しません。
- 砂・荒地のテクスチャを草地へ切り替えます。水辺・水底にも適用します。この表示設定はセーブに保存されません。
- 開発版です。ビルドと自動チェックは実施済みですが、最新の実ゲーム内挙動と全MODとの互換性は未検証です。元のセーブを残してください。

## ビルドと公開ソース

.NET SDK、NuGetで復元する.NET Framework 3.5参照アセンブリ、ご自身が所有するゲームのManaged DLLが必要です。

```powershell
.\build.ps1
.\build.ps1 -GameManaged 'D:\SteamLibrary\steamapps\common\Cities_Skylines\Cities_Data\Managed'
dotnet run --project .\Checks\Checks.csproj -c Release
```

日英統合版と公開用ソースZIPをdistへ出力します。ゲームDLLを配布物に含めません。UnifiedUILib.dllはMITライセンスで、ライセンス文を同梱しています。本MOD独自コードのオープンソースライセンスはまだ指定していません。

Workshopフォルダーに日英合計4000字以内の説明文と、512×512のサムネイルがあります。サムネイルはAI生成の宣伝用イラストで、実際のゲーム画面ではありません。
